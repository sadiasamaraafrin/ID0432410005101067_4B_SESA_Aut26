# Blood Bank Management System

## How to Run Locally
1. Open **CMD** inside the project folder.
2. Run: `npm install`
3. Run: `node server.js`
4. Open `http://localhost:3000` in your browser.

## Login Credentials
Enter either set of credentials on the login screen:

- **Admin Account** (full access: manage users, delete records, view activity logs)
  - **Username:** `admin`
  - **Password:** `admin123`

- **Lab Staff Account** (standard lab operations: donors, stock, requests, camps, reports)
